Configura tu base de datos

Necesitas crear una cuenta gratuita en Supabase para guardar el progreso del equipo. Son 10 minutos y es gratis para siempre con equipos pequeños.

1
Crea cuenta en Supabase
Ve a supabase.com → New project → elige un nombre (ej: pe-ai-course) y una contraseña de base de datos.
2
Ejecuta el SQL de setup
En tu proyecto de Supabase, ve a SQL Editor y pega este código:
create table progress (id uuid default gen_random uuid() primary key, user_id uuid references auth.users, skill_id text, subtask_id text, completed boolean, updated_at timestamp default now(), unique(user_id, skill_id, subtask_id));
3
Copia tus credenciales
En Supabase: Settings → API. Copia la Project URL y la anon public key.
